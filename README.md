  # 🐍🍉 Змея и Арбуз

**Anti-AI Snake & Watermelon** — браузерная 3D-аркада на Three.js.  
Змея толкает арбуз по трассе, а игрок подбрасывает его через брёвна, камни и кусты.  
Доехал до финиша — получил награду. Разбил арбуз — начинай сначала!

## 🎮 Как играть

| Действие | Управление |
|----------|-----------|
| **Подбросить арбуз** | `Пробел` / `↑` / `W` / большая кнопка ⬆ на экране |
| **Цель** | Провести арбуз от 0% до 100% трассы за 3 минуты |
| **Жизни** | 🍉🍉🍉 — три попытки. Удар о препятствие снимает одну |
| **Награда** | 🐍 Красная змея — за прохождение трассы до конца |

Арбуз катится впереди, змея подталкивает его сзади. Скорость постепенно растёт — от 1.2 до 2.6.  
На трассе случайно расставлены препятствия трёх типов: **бревно**, **камень**, **куст**.  
Если подбросить арбуз вовремя — он перелетит. Если нет — трещина, минус жизнь, скорость падает вдвое.

## ✨ Особенности

- 🎯 **Простая механика в один тап** — играть можно одной рукой с телефона
- 🌍 **Два языка** — русский и английский, переключение на лету
- 🗣️ **Озвучка** — приветствие, победа, проигрыш, удар через Web Speech API
- 📱 **Mobile-first** — отдельные оптимизации под телефоны (низкое качество теней, ограничение pixelRatio)
- 🎨 **Живая 3D-сцена** — солнце, облака, холмы, тени в реальном времени
- 🏆 **Доска почёта** — за победу начисляется награда и отправляется в общий рейтинг проектов
- ❤️ **Free to play** — без рекламы, без регистрации, без сбора данных

---

## 🛠️ Технологии

- **Three.js r128** — 3D-движок (WebGL)
- **Vanilla JavaScript** — без фреймворков
- **Web Audio API** — процедурные звуки (подброс, удар, победа, проигрыш)
- **Web Speech API** — голосовые подсказки
- **Vibration API** — тактильная отдача на телефонах
- **CSS Glassmorphism** — интерфейс в стиле «матового стекла»

Никаких сборщиков, зависимостей и node_modules — **один HTML-файл**.
